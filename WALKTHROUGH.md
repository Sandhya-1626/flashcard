# AI Flashcard Battle - Project Walkthrough

Welcome to **AI Flashcard Battle**, a high-octane education game designed to make revision addictive and effective.

## ✨ Features

### 1. Dynamic Arena Generation
- Enter any topic, and the system prepares a custom set of flashcards.
- Supported topics (pre-built): `Python Variables`, `Biology - Cell Structure`.
- Generic topics are intelligently proxied with fundamental questions.

### 2. Triple Threat Game Modes
- **1 vs AI**: Race against our "Battle-Bot" to see who can master the topic faster.
- **Time Attack**: Push your limits! 60 seconds to answer as many cards as possible.
- **Survival**: Pure perfection required. One wrong move and your run ends.

### 3. Spaced Repetition Engine (Simulated)
- The system tracks your progress. 
- In non-timed modes, cards loop back after answering, ensuring you encounter difficult topics multiple times until mastery.

### 4. Advanced Analytics
- Post-match breakdown includes:
  - **Final Score**: With streak multipliers.
  - **Accuracy Percentage**: Tracking your precision.
  - **AI Insights**: Encouraging feedback based on performance.
  - **Revision Suggestions**: Targeted focus areas.

## 🛠️ Tech Stack
- **Framework**: Vite + React + TypeScript
- **Styling**: Vanilla CSS (Modern Design System)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Celebration**: Canvas Confetti

## 🚀 Getting Started
1. Run `npm install`
2. Run `npm run dev`
3. Enter your study topic and conquer the arena!
